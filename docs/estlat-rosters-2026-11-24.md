Added a dated 2026/27 directory of 222 official person IDs across 15 teams.

searchable as Jordan Tillmon and retains the existing `elb-32585` profile URL.
Keila Basket (`elb|KEI`) and Keila KK (`elb|KE1`) remain separate clubs.

Evidence: the official 2026/27 team directory at
https://www.estlatbl.com/et/voistkonnad and the published player directory
included on https://www.estlatbl.com/et/mangijad?pid=16278 . Individual
biographies use the person links embedded in that directory, including
https://www.estlatbl.com/et/mangijad?pid=32585 . The Rīgas Ekselences Juniori
roster additionally supplies biographies at
https://www.estlatbl.com/et/osalevad-voistkonnad/10028/rigas-ekselences-juniori/roster .

This is a manual evidence import from accessible official web/search snapshots;
their observation dates differ. It does not claim live completeness or a new
automatic collection route. The collector's source restrictions are unchanged.
There are 107 accessible official biographies, 61 biographies retained from
the same stable person ID in historical data, 17 identities corroborated by
matching full name and current club in another official competition, and 37
incomplete biographies requiring review. Missing values remain unknown.

Historical statistics and user records are not rewritten. Stable source IDs
link older profiles; unknown identities are not joined merely by a name.
Registration is season roster evidence, not a contract-expiry or health claim.
No game statistics or departures were invented. A later connected EstLat
roster pack supersedes this bundled fallback. The directory remains available
if the statistics cloud connection is temporarily unavailable.

Validation covers repeat loading, same-name isolation, official-ID linking,
the two Keila clubs, source precedence, missing statistics, and disconnected
loading. A focused browser check uses the real historical EstLat data and
published directory to verify Tillmon's profile and Scouting Matchup club.
